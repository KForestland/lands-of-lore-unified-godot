# Hive reinforcement state

The source Hive startup records enable three warriors after Shalla's rescue and four after meeting Bacatta. This restoration-owned state module retains activation, health, position, attack clocks and reward randomness without recreating defeated actors. Admission, numeric source bindings, JSON restoration and malformed-packet rejection have a portable test.

```sh
flatpak run org.godotengine.Godot --headless --path . --script res://tests/hive_return_population_state_test.gd
```

Verified in an isolated checkout without original game media or saves. The JSON contains numeric verification results and hashes, not original archive payloads. Runtime source positions and400-health values are checked against the pinned local game source; reward scale is8.

The local live controller additionally connects pursuit, melee/Spark/aura hits, rewards and area transport. That asset-dependent controller is not included in this PR. Exact native startup owner-list lifetime remains unresolved: local arrival scheduling preserves activation and defeat and skips startup on disk restore. Movement, attack cadence, collision dimensions and static sprite presentation remain provisional. This does not close original combat parity or full Act One.
