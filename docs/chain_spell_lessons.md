The shared magic owner admits teaching only during playable, living, unpaused casting conditions, then uses the same learned-group API as normal acquisition. A learned required cast skips its site, including a partial modern group; a missing required cast learns the same group as normal acquisition. Teaching does not change mana, health, selected school, inventory, curse phase, native cells or quest outcome. The existing book packet saves it through ordinary F5/F9. Legacy inference and F2 starts retain their separate existing rules; a modern empty book is not filled merely because it loads a later chapter.
