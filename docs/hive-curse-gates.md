# Hive curse gate state

This detached state module models original timer gates389/391/392/393/812/818 and one-shot human-return commands at391/818/1259/1260. The second gate pair requires the existing runes-translated flag to be zero. Command04 consumes its source request once admission is enabled and the player is nonhuman; command3c remains repeatable. Saved use history is validated and restored with canonical JSON numbers.

The numeric fixture contains256 independently replayed predicate cases. Local native verification additionally covers36 command dispatch cases and24 human-request cases. No original executable bytes, geometry, art, audio or saves are included. Authored seconds and RNG remain explicit adapters; native command mutation persistence across level reload is unverified. The live controller, polygons and rendered checks remain in the research workspace.

Run in this checkout:

```sh
flatpak run org.godotengine.Godot --headless --path . --script res://tests/hive_curse_state_test.gd
```

The test checks translation admission, timer reset/stop, per-command one-shot behavior, repeatable command3c, legacy JSON-compatible state and malformed-history rejection. This PR does not establish Act One completion.
