# Hive Dawn20 integration checkpoint

The local game now connects the monastery library attack to Dawn’s alternate Hive rune translation. The library reaction sets the original absence/attack flags and soul change; that state survives save/load, a return to the room, and the Jungle-to-Hive handoff. Rune-room entry queues the original conditional appearance; dialogue, offers, hit transition and removal on re-entry are integrated.

Independent main-worktree validation passed eight focused tests: the Dawn state and rendered encounter, library native planner and rendered attack/handoff, Hive and Jungle saves, rune transaction and monastery side rooms. The original library handler replay independently reproduced all32 cases. These tests supply the library prerequisites and copied runes; they are not a fresh full campaign.

This GitHub checkpoint publishes the portable library planner, numeric native evidence and test. Run `godot --headless --path . --script res://tests/monastery_library_attack_portable_test.gd`. The rendered host, original movies and full local dependency tree are not included in this component PR.
