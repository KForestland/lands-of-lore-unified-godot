# L10 object parts and rooms

Movable lids, crypt tops and panels, plus source assemblies drawn by generic or feature owners, follow the existing room renderer. There are56 generic mover parents and84 controlled assembly parents, including29 generic breakable covers and the Emperor/tomb/slab parts.

The binding retains the placement's native region. A cabinet region can be only20 units high; its exposed front also belongs to the exterior room touching its published faces. Additional memberships require actual face footprint contact, overlapping vertical air and membership in the primary room's original native potential set. The one-unit existing portal border tolerance covers boundary faces. There is no fixed outward probe. JSON room numbers are normalized to integer sets. Unrelated stacked rooms stay outside the binding.

A parent draws when any of its bound rooms draws. Child presence and selector artwork remain owned by the original feature. Hiding a room changes no collider, native state or save. Selector rebuilds retain the parent, and showing a room cannot revive an absent child.

For L10 drawing, the starting room comes from the highest native floor below Luther's feet with air above it. The script owner's cached XY region can name an overhead cell after another body position, so drawing does not reuse it when the physical floor resolves. Script entry and collision owners are unchanged; unresolved space retains the old fallback.

Qualification includes a rendered all-binding/presence/selector/collider invariant, the original real-input table with visible vantages, and the earned lid117 route. The original table can supply a collision-clear stand under the supply ledge; the visibility variant instead requires a clear stand that actually shows the part before accepting it, then performs the same real strikes. These supplied stands/root/NPC clocks and controlled draw fixtures are explicitly source-site audited, not earned walks. The separate lid117 continuation uses its untouched game-written input, real W/E, ordinary1/60 and zero recovery.
