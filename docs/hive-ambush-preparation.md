# Hive ambush-pack preparation

```sh
python3 tools/prepare_hive_ambush_pack.py --game /path/to/original/game --recipe scripts/lol2/hive_ambush_preparation_source.json --geometry /path/to/fresh/L5_HC/geometry/geometry.json --output-root /path/to/fresh/output
```

Prepare the geometry with the published Hive geometry exporter first. This command requires Pillow, NumPy, FFmpeg and ffprobe plus the published source/movie readers. It checks the original Hive and movie archives, the geometry source binding and the complete recipe hash. No historical workspace export or native verifier is loaded.

The compact recipe retains original HW07/EX05/EX06 movie bindings, five historically verified constructor results and two nest-clip comparison records. Its provenance pins the original trigger report and nest review. These retained records are not new constructor evidence. Geometry must be a fresh unedited export: source identity is checked, but supplied vertices are not independently regenerated by this command.

The complete runtime pack has three keyed atlases and `ambush.json`. All 96 RGB frames are decoded, counted and hashed; placements and template records are reread from the originals. Lead verification reproduced all three PNGs byte-for-byte. The manifest is equal after normalizing FFmpeg process memory addresses in diagnostic strings. Raw diagnostics and extracted movies remain under `tmp/hive_ambush`; FFmpeg's recorded NINL/end-of-demux warnings are retained, with successful exit and complete frame counts checked.

An isolated committed-source run loaded no native/RE modules. Five refusal controls cover existing output, overlap, missing originals, wrong recipe and wrong geometry. Output must be fresh and outside all inputs. Failures during decoding can leave partial staging output for diagnosis.

The legacy `prepare_hive_ambush_media.py` remains unchanged. Exact chroma keying, billboard anchors and existing scope limits are preserved; source trigger sequencing, live admission, loop policy and native world scale are not newly verified. Generated media stays outside source publication.
