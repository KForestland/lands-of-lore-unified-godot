# LoL2 in Godot: status report

Date: 2026-10-31

This note describes the local working project. The code in this repository is an
older public snapshot (September 2026); most of the work below is not published here.

Target: the complete original Lands of Lore II in Godot. The **Classic** edition keeps
the original's behaviour, with every original bug fixed and every deviation logged.
An **Enhanced** edition comes later on the same engine.

## Where it stands (Classic edition)

| Part | Done | Notes |
|---|---|---|
| Act 1 (Cave, Museum, Jungle, Hive, Dark Halls) | ~85-90% | Playable start to finish. Owner playtest 2026-10-31: "few issues". Village and some puzzles saved for the end. |
| Maps, all acts | ~80% | All 10 Act 2-3 maps built and walkable; exits between levels being connected, 3 waiting on decoding. |
| Story scripts (puzzles, doors, events) | ~40% | About 42% of the original's script groups run on the native script host; Acts 2-3 mostly to do. |
| Items, game-wide | ~20% | Act 1 items work; the rest is the next phase after maps. |
| RPG (stats, levelling) | ~10% | Not started properly. |
| Dialog and dialog logic | ~15% | Village dialog broken (Bacatta turns hostile). |
| Combat, magic, sound | ~25% | Basics only; these come last. |

**Overall: roughly 40-45% of a complete Classic LoL2.** The hardest groundwork is done:
the engine, the native script host, the map builders and the test system.

## Phase order (agreed with the owner)

Maps -> items -> RPG -> dialog and dialog logic -> small fixes. Sound and combat polish last.

## Estimated time (rough, not a deadline)

- All maps connected, whole game travelable: about 1-2 weeks.
- Story playable start to finish: about 2-3 months.
- Items, RPG and dialog working game-wide: about 3-4 months.
- Polished, complete Classic edition: about 5-7 months. Enhanced edition after that.

The main uncertainty is decoding the script commands used heavily in Acts 2-3
(opcodes 196 and 204).
