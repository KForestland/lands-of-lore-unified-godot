The port's one static collision mesh collided everything. jungle_review now keeps the static collision per owning region (one CollisionShape3D per region under "RegionCollision"; faces without a region stay always on) when region_collision_enabled, and act2_map (REGION_COLLISION_AREAS = L17_HC, L19_BC) enables only the regions within COLLISION_HOPS = 8 nav hops of the player's region (links: the creature nav's stored edges plus polygon sides shared within 48 of floor, region_edge_rule.links). The player's region is tracked like the original's: it stays while the body is inside its polygon, leaves only into a linked neighbour, and is placed afresh only when it lies in neither (progression.region_at), so an overlapping layout never captures the body.
